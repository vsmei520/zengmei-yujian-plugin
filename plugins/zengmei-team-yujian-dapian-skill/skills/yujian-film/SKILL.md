# 曾美团队·育见大片

这是曾美团队的远程强保护 Skill 入口。

## 执行规则

1. 不在本地复述、重建或猜测核心 Skill 规则。
2. 使用本插件的远程执行脚本，把用户输入和已确认的 `10s` 或 `15s` 模式提交到曾美团队服务端。
3. 服务端不可用、授权失效或返回版本不兼容时，明确告知用户，不使用本地规则替代。
4. 不把访问令牌、服务端响应中的内部策略、调试信息或授权信息输出给用户。
5. 只向用户展示服务端返回的最终创作结果。

## 本地执行入口

```powershell
pwsh -File ./scripts/run-remote.ps1 -Profile 10s -InputFile <input.json>
```

`Profile` 只能使用 `10s` 或 `15s`。输入文件应为 UTF-8 JSON，具体字段由服务端接口版本决定。

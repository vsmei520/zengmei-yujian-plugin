# 曾美团队·育见大片

这是曾美团队的远程强保护 Skill 入口。

## 执行规则

1. 不在本地复述、重建或猜测核心 Skill 规则。
2. 优先使用本插件提供的远程 MCP 工具，不要求用户运行 PowerShell、Node 或其他命令。
3. 第一次使用时，如果没有授权信息，向用户索要曾美团队授权码，然后调用 `activate_license` 完成授权。记住工具返回的 `accessToken`，仅作为后续工具的内部参数。
4. 根据用户要求选择 `10s` 或 `15s`，调用 `generate_content`，把用户提供的内容、授权码和内部 `accessToken` 提交到远程服务。
5. 服务端不可用、授权失效或返回版本不兼容时，明确告知用户，不使用本地规则替代。
6. 不把 `accessToken`、服务端响应中的内部策略、调试信息或授权信息输出给用户。
7. 只向用户展示服务端返回的最终创作结果。

## 授权提示

管理员在 `https://yuer.073955.com/admin` 创建授权码。普通用户只需要在对话中提供授权码，插件会通过远程工具完成激活。

`Profile` 只能使用 `10s` 或 `15s`。核心规则不在插件内，始终由服务端执行。

## 推荐启动词

首次使用，直接发送：

```text
启动曾美团队·育见大片。我选择 10 秒版本，已上传原片视频和 Skill 文件，请读取完成后按 Skill 第一阶段开始执行。
```

需要 15 秒版本时发送：

```text
启动曾美团队·育见大片。我选择 15 秒版本，已上传原片视频和 Skill 文件，请读取完成后按 Skill 第一阶段开始执行。
```

如果希望授权后直接生成，可发送：

```text
启动曾美团队·育见大片，使用 10 秒版本直接生成。授权码：你的授权码。原片视频和 Skill 文件已上传，请按固定提示词执行。
```

如果插件第一次提示授权，只需要单独发送管理员提供的授权码即可。

# 宝塔最简部署

## 1. 上传

把 `server` 文件夹上传到：

```text
/www/wwwroot/yuer.073955.com/server
```

## 2. 设置环境变量

在宝塔 Node 项目或 PM2 环境变量中设置：

```text
PORT=3100
ADMIN_KEY=请替换成你自己的管理员密码
```

不要把 `ADMIN_KEY` 写进网页文件或提交到公开仓库。

另外，把两份核心 Skill 文件放到：

```text
/www/wwwroot/yuer.073955.com/server/core/skill-10s.md
/www/wwwroot/yuer.073955.com/server/core/skill-15s.md
```

这两份文件不上传 GitHub。

## 3. 启动

在 `server` 目录运行：

```bash
node server.js
```

或者使用宝塔 Node 项目管理器：

```text
启动文件：server.js
项目目录：/www/wwwroot/yuer.073955.com/server
端口：3100
```

## 4. 反向代理

网站 `yuer.073955.com` 添加反向代理：

```text
目标 URL：http://127.0.0.1:3100
```

反向代理后要确认以下地址能打开：

```text
https://yuer.073955.com/health
https://yuer.073955.com/admin
```

然后访问：

```text
https://yuer.073955.com/admin
```

## 5. 生成授权码

打开管理页面，输入 `ADMIN_KEY`，选择有效期，点击“生成授权码”。

后台支持：

- 用户名称和联系方式
- 激活码
- 创建时间
- 首次激活时间
- 到期时间
- 设备绑定状态
- 解绑设备并允许新电脑重新绑定
- 停止使用
- 恢复使用

授权码数据保存在：

```text
server/data/licenses.json
```

每个授权码首次激活时会绑定到当前插件安装设备。这个版本不需要数据库，也不需要本地运行授权命令。

需要换机时，先在授权后台点击该用户的“解绑设备”。旧电脑会立即无法继续使用；新电脑使用同一授权码激活后，会自动绑定新电脑。

后台“生成服务”只检查核心 Skill 是否就绪。模型接口、密钥和模型名称由每位用户在自己的插件本机配置，服务器不会保存用户模型密钥。

## 6. 更新规则

核心 Skill 规则放在服务器时，直接替换服务器端规则并重启 Node 项目即可生效。

插件壳更新时：

1. 修改插件 `.codex-plugin/plugin.json` 的 `version`
2. 将插件目录更新到远程 marketplace 仓库
3. 用户刷新或重新安装插件

授权后台地址保持不变，不需要重新生成授权码。

## 7. 用户安装和使用

用户在 Codex 的插件市场中添加你的 GitHub 仓库并安装插件，不需要运行 PowerShell。

安装后，用户直接说：

```text
使用曾美团队·育见大片，生成 10 秒版本
```

第一次使用时，按下面顺序完成：

1. 用户在 Codex 对话中发送授权码，插件自动绑定当前电脑。
2. 插件会显示一个 `http://127.0.0.1:端口号` 的本机设置链接。用户点击或复制到本机浏览器打开。
3. 用户填写自己的模型平台提供的“完整接口地址”、API 密钥和模型名称，点击“保存模型设置”。
4. 回到 Codex，重新发送启动词即可开始生成。

用户的模型接口必须是可从互联网访问的、兼容 OpenAI `chat/completions` 的 HTTPS 接口。用户本机的 `127.0.0.1` 模型接口不能使用，因为实际生成请求由宝塔服务器发出。

用户自行向自己的模型平台支付模型调用费用。服务端只在本次生成请求中临时使用密钥，不保存，也不会在授权后台显示。
